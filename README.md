
<h1>School Database Management System using SQL</h1>

<h2>About the Project</h2>
<p>
  This is a beginner-level SQL project developed to practice basic database
  management skills using MySQL. The project focuses on creating and managing
  a school database for students, teachers, and subjects.
</p>

<h2>Features</h2>
<ul>
  <li>Create a school database and tables.</li>
  <li>Insert student, teacher, and subject records.</li>
  <li>Retrieve and display data using SELECT.</li>
  <li>Sort student records using ORDER BY.</li>
  <li>Use column aliases with AS.</li>
  <li>Update student and teacher information.</li>
  <li>Rename tables using RENAME TABLE.</li>
</ul>

<h2>Technologies Used</h2>
<ul>
  <li>MySQL</li>
  <li>SQL</li>
</ul>

<h2>Database Tables</h2>
<ul>
  <li><strong>students:</strong> Stores student information and academic records.</li>
  <li><strong>teachers:</strong> Stores teacher information and office numbers.</li>
  <li><strong>school_subjects:</strong> Stores school subject names.</li>
</ul>

<h2>What I Learned</h2>
<p>
  Through this project, I practiced basic SQL commands, created database
  tables, inserted and updated records, retrieved data, and performed
  simple database operations.
</p>
